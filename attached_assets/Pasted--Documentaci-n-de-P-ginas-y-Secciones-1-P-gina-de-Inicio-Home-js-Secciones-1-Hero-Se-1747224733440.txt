# Documentación de Páginas y Secciones

## 1. Página de Inicio (Home.js)
### Secciones:
1. **Hero Section**
   - Título principal: "El buscador para importar vehículos clásicos a Argentina"
   - Botones de acción:
     - "Buscar Vehículos" (redirige a /busqueda)
     - "Guía de Importación" (redirige a /guia-importacion)

2. **¿Por qué usar ClasicAR?**
   - Tres características principales:
     - Verificación de Elegibilidad
     - Ahorro de Tiempo
     - Costos Transparentes

3. **¿Cómo Funciona?**
   - Tres pasos principales:
     - Busca: Filtros para encontrar autos
     - Verifica: Detalles y elegibilidad
     - Importa: Guía paso a paso

4. **Acerca de**
   - Información del desarrollador
   - Enlaces de contacto:
     - Email
     - Twitter
     - WhatsApp

## 2. Página de Búsqueda (Busqueda.js)
### Secciones:
1. **Filtros de Búsqueda**
   - Filtros por:
     - Marca
     - Modelo
     - Año
     - Precio
     - Estado
     - Ubicación

2. **Resultados de Búsqueda**
   - Grid de vehículos
   - Información básica de cada vehículo
   - Opciones de ordenamiento

2. **Información del Vehículo**

3. **Calculadora de Importación**

   - Impuestos aplicables
